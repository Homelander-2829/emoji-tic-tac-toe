# Emoji Tic Tac Toe 🧠

A fun emoji-based Tic Tac Toe game built with React, TailwindCSS, and Framer Motion.

## Live Demo

Check out the live project here:  
[https://homelander-2829.github.io/emoji-tic-tac-toe]
(https://homelander-2829.github.io/emoji-tic-tac-toe)

## Features

- Play Tic Tac Toe using emoji sets
- Smooth animations with Framer Motion
- Confetti celebration on win
- Responsive design with TailwindCSS
- Restart game with option to keep or change emoji sets

## Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/homelander-2829/emoji-tic-tac-toe.git
cd emoji-tic-tac-toe
npm install
```

## Run Locally

```bash
npm start
```

## Build and Deploy

Build the app for production:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```
